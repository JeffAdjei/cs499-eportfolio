3D Graphics Rendering Project (CS 330)

Narrative · Original & Enhanced Artifact Reflection

This artifact is a 3D graphics rendering system developed in CS 330 using OpenGL. I selected this artifact because it allowed me to demonstrate algorithmic thinking within a visual and performance-sensitive environment. I enhanced the project by restructuring repetitive rendering logic and improving input handling. These changes reduced redundancy and improved scalability, demonstrating my ability to apply data structures and algorithmic principles to optimize system performance. This experience strengthened my ability to analyze existing systems and redesign them for efficiency.

What the enhancement demonstrates

Rendering PipelineStructured render stages for clarity and reuse.
Reduced RedundancyShared mesh & camera logic moved into reusable modules.

Input HandlingCleaner input-to-camera mapping for extensibility.
