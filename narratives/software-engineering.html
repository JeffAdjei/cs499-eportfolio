Weight Tracking Mobile App (CS 360)

Narrative · Original & Enhanced Artifact Reflection

This artifact is a mobile weight tracking application developed in CS 360. I selected this artifact because it demonstrates core software engineering principles, including user interaction, data persistence, and application structure. I enhanced the artifact by improving input validation, refining UI layout consistency, and restructuring database interactions. These improvements demonstrate my ability to design maintainable applications, handle user input safely, and implement structured application logic. Through this process, I strengthened my understanding of modular design, validation strategies, and user-focused development.

What the enhancement demonstrates

Input ValidationStronger checks on login, account creation, and weight entry.
Modular DesignActivities refactored into focused helper methods.
Database LayerCleaner SQLite helper structure with clearer responsibilities.
MaintainabilityDocumentation added for readability and future iteration.
